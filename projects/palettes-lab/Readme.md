# palettes-lab

A **hand-written** (non-VM8) game over a world that uses every option of the
studio's **Palettes** dock. The world is the same as `vm-palettes`; what differs
is that `src/palettes_lab.mos` is ordinary code that loads the colour itself.

| Dock tab | What this world has |
|---|---|
| Library | 14 palettes: `ui` (made with **From tileset**) and 13 authored ones |
| Scene slots | `meadow` loads the **World default** rows; `cave` has its **own** rows |
| Paint | a slot per tile, slots 4..6 in the cave, and a mossy wall split into `tiles_split.png` |
| Sprites | per-cell slots on the hero, kind slots on the villager and the gem |
| DMG | BGP `0xE4`, OBP0 `0xD0`, OBP1 `0xE0`, applied by `dmg_registers()` |
| Consoles | folds on SMS / Game Gear / NES / PC Engine, NES attribute areas, the shared NES / PCE backdrop, Lynx slot 0 |

Controls: **A** goes to the other room, **B** turns night on and off (a runtime
write into background slot 1 with `scenes.set_palette`).

The scenes-module calls a hand-written game makes, in order: `load_palettes`,
`paint` (on SMS / Game Gear this uploads the tiles through their slots),
`paint_attrs`, `paint_actor` for per-cell sprites and `KIND_PAL` for kind slots.
On SMS / Game Gear a sprite's slot rides its sheet upload (`palette.set_2bpp`).

Targets all seven consoles a world builds for, NES included. Generated by the
studio repo's `tools/gen_samples/palettes_lab_world.py`. `verify.py` checks the
GBC ROM.
