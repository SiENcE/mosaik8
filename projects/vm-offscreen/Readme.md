# vm-offscreen

Actors the camera has not reached yet. A VM8 sample with `[build]
actor_deactivate` on (the reference engine's offscreen deactivation), a 24-slot actor
pool and `[build] actor_scan = 4`, built as the subject of two engine ROM
tests:

| room | shape | what it proves |
|---|---|---|
| `gate` (0, start) | one screen, no actors | a boot save-state with NO animator armed, so "entered directly" really is direct |
| `yard` (1) | one screen, twelve animated blobs, all visible | all twelve animators are armed when the player leaves |
| `road` (2) | 80 tiles wide, twenty-four blobs 24 px apart | eighteen slots start PARKED right of the entry camera; walking right wakes them one by one |

- `tests/actor_wake_latency_test.py` holds RIGHT in the road and asserts, per
  game frame, that no parked slot stays parked on the window for longer than
  the `actor_scan` budget (`vm.actor.wake_scan`).
- `tests/room_change_animator_leak_test.py` compares what the road arms when
  reached via the yard against what it arms from a fresh boot
  (`vm.canim.sweep_retired`), and pins `n_on == count(a_count > 0)` along a
  long route.

Nothing is scripted: no actor moves and nothing locks the VM, so the camera is
the only thing that can move a slot on or off the live list. Both tests build
a temp copy of this project and relink it with `-Wl-j`
(`tools/framebudget/build_noi.py`) so the ROM and its symbols come from the
same link.

All art is procedurally generated by `assets/gen.py`.

## Build / verify

```
python projects/vm-offscreen/assets/gen.py
python mosaik8.py build --platform gameboy projects/vm-offscreen
python projects/vm-offscreen/verify.py
```

`verify.py` runs the two engine tests above (each builds its own copy).
